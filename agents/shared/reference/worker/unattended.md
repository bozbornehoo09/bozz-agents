# Unattended mode

- Never wait on the owner. An architect settles each new design call with
  `deciding-calls-by-debate`, which applies, records or parks it. An
  implementer never debates: a departure from the plan becomes an owner item.
- Housekeeping you decide yourself; it is never parked.
- Owner-go steps still wait for the owner, a draft pull request included.
- Wherever a rule says to report `WAITING-ON-OWNER` (a blocked checkout, a
  stale lock), record a blocked item under `Open owner items` instead and keep
  working.
- Do all the work that no parked call or blocked item stands in the way of.
  Once only blocked work is left, hand off with the line
  `Blocked: all remaining work waits on <items>`.
